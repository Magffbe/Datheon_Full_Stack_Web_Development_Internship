
# Task 1 — Personal Developer Portfolio

## Overview

A responsive personal portfolio website developed as part of the Datheon Full Stack Web Development Internship.

The portfolio showcases my web development projects, technical skills, certifications, and professional contact information.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive layout for desktop, tablet, and mobile devices.
- Interactive navigation menu with mobile hamburger toggle.
- Hero section with animated role titles.
- Projects showcase with live demos and external links.
- Skills and technologies section.
- Certifications showcase.
- Contact form integrated with Netlify Forms.
- Social media and professional profile links.
- Downloadable CV.
- Canvas-based particle background.
- Accessibility considerations and reduced-motion support.
